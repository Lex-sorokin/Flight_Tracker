# ✈️ Flight Tracker — Система мониторинга воздушных судов

Проект представляет собой приложение на Python для сбора данных о самолетах, находящихся в воздухе в реальном времени, с сохранением информации в базу данных **PostgreSQL** и возможностью аналитики через класс `DBManager`.

## 📋 Описание функционала
1. **Сбор геоданных:** Получение координат границ (bounding box) для списка из 10 стран с помощью публичного API [Nominatim (OpenStreetMap)](https://openstreetmap.org).
2. **Мониторинг рейсов:** Получение актуальных векторов состояния воздушных судов в заданных координатах через API [OpenSky Network](https://opensky-network.org).
3. **Хранение данных:** Автоматическое создание таблиц `countries` и `aeroplanes` в PostgreSQL и загрузка в них собранной информации.
4. **Аналитика (`DBManager`):**
   - Подсчет количества самолетов в воздушном пространстве каждой страны.
   - Получение полного списка отслеживаемых воздушных судов.
   - Расчет средней скорости полета по всем бортам.
   - Фильтрация самолетов со скоростью выше средней.
   - Поиск рейсов по ключевым символам в позывном (без учета регистра).

## 🛠 Технологический стек
* **Язык:** Python 3.10+
* **База данных:** PostgreSQL
* **Библиотеки:**
  * `requests` — выполнение HTTP-запросов к внешним API.
  * `psycopg2-binary` — драйвер для работы с PostgreSQL.
  * `python-dotenv` — управление переменными окружения.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <ваша-ссылка-на-репозиторий>
cd flight_tracker
```

### 2. Создание и активация виртуального окружения
**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```
**Для Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных и переменных окружения
1. Убедитесь, что у вас установлен и запущен **PostgreSQL**. Создайте пустую базу данных (например, `flight_tracker`).
2. Скопируйте файл `.env.example` и переименуйте его в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Заполните `.env` своими данными для подключения к PostgreSQL:
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=flight_tracker
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль
   ```

### 5. Запуск приложения
```bash
python main.py
```

## ⚠️ Примечания по работе с API
* **Nominatim API** имеет ограничение не более 1 запроса в секунду, поэтому при сборе координат 10 стран скрипт делает небольшую паузу (~11 секунд).
* **OpenSky Network API** при анонимном подключении ограничивает количество запросов в сутки (400 кредитов). Один полный запуск программы расходует около 15–20 кредитов.
